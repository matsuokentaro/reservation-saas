# Reservation Manager

Laravelで開発した予約管理システムです。

## 概要

店舗予約を管理するためのWebアプリケーションです。

予約の登録から来店完了までのステータス管理を行うことができます。

## 機能

- ログイン認証
- 店舗管理
- 予約管理
- 予約検索
- ステータス管理
  - 予約受付
  - 予約確定
  - 来店済み
  - キャンセル
- ダッシュボード
- サイドバーUI

## 使用技術

- PHP
- Laravel
- Blade
- MySQL
- CSS
- Git / GitHub

## 画面

### ダッシュボード

予約状況を確認できます。

### 予約管理

予約の登録・編集・削除、
ステータス変更を行えます。

### 店舗管理

店舗情報の登録・編集・削除を行えます。
